This is the unified dashboard and Backend-for-Frontend (BFF) for the entire agent fleet.

The BFF on port 8787 proxies requests to all agent backends.

- Database: PostgreSQL, Redis

- Deploy: Docker (nginx + node + postgres + redis + flowise), Hostinger VPS, Coolify
