# Dashboard Agent Swarm - Architecture

This is a multi-agent dashboard/swarm platform with:
- Frontend: Vite + React + TypeScript + Tailwind
- Backend: Express/Bun server with SQL
- Agents: Multiple agent implementations (lemonai, researcher, etc.)
- CLI tools: npx, hermes
- Database: Supabase/PostgreSQL
- Desktop: Electron shell
- Mobile: React Native
- Archive: ai-agent-platform monorepo
- CI/CD: Docker, Coolify, Contabo
